# Cursor — From Idea to Reality (AVE Studio spec commercial)

A 40-second 16:9 spec spot for Cursor, built as code. Not affiliated with or endorsed by Cursor; the end card says so.

## Deliverables (`film/build/`, not committed except the final MP4s)
- `Cursor_Spec_AVE_16x9.mp4` — 1920×1080, 60 fps, H.264, stereo, −14 LUFS.
- `Cursor_Spec_AVE_16x9_NoMusic.mp4` — same picture, sound design only.
- Stems: `music.wav`, `sfx.wav` (they sum to `mix_raw.wav`).
- `thumbnail.png` — key visual.

## Structure
| Path | What it is |
| --- | --- |
| `storyboard/` | The approved storyboard (16:9). |
| `assets/brand/` | Official logo files from cursor.com/brand (2.5D cube, lockups, wordmark), used unmodified. |
| `film/cues.js` | The single timeline. Picture and sound both read it. Keystroke times are generated by `make_typing.py`. |
| `film/index.html` | The film. `window.seek(t)` paints any frame as a pure function of time. |
| `film/audio.py` | Original score + sound design → stems and mixes. Uses slices of the supplied UI SaaS SFX pack (`film/sfx/`). |
| `film/render.mjs` | Headless Chromium → frames → H.264 (CRF 16). |

## Rebuild
```bash
cd film
python make_typing.py            # only if typed text or timing changes
python audio.py                  # numpy + scipy; writes build/*.wav
node render.mjs --video=build/video.mp4
# loudnorm build/mix_raw.wav to -14 LUFS (two-pass), then mux:
ffmpeg -i build/video.mp4 -i build/mix.wav -c:v copy -c:a aac -b:a 320k -shortest build/Cursor_Spec_AVE_16x9.mp4
```

## Honesty notes
- The editor, Tab and Agent shots are illustrative recreations in Cursor's visual style, not screen recordings. The code shown is real, working TypeScript/React, and the dashboard is built from exactly the components the Agent edits.
- Dashboard numbers are sample data.
- Typeface: Inter (UI/type) and JetBrains Mono (code); Cursor's own typeface is not in the public kit.
