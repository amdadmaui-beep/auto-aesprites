# AVE Studio — next builds (saved for later)

Agreed on 2026-11-02. Not started yet; pick these up in this order unless told otherwise.

## 1. Clip-finder (AI tool for the editing workflow)
- Input: a long podcast or stand-up set (file or Drive link).
- Transcribe, then score every 20–60s window for viral potential: hook strength in the first 2s, punchline or payoff, emotion and energy, self-contained story, quotable line.
- Output: the top N moments, pre-cut to 9:16, with captions in AVE's style (lime keyword highlights, punchline emphasis), plus a short "why this moment" note per clip.
- Reuse: the caption and framing code from `reel/` and `film/`, and the Drive download path used for the showcase clips.

## 2. Deep research report: target list
- Question: who are the ~200 fastest-growing stand-up comedians and podcasters on TikTok, and what do their best clips have in common?
- Method: parallel research agents; every claim sourced.
- Output: a sourced report (patterns in hooks, length, captions, posting cadence) and a target list written into the "AVE Studio — Prospecting CRM & Weekly Pipeline" sheet in Drive, with a short note on why each one fits AVE.
- Feeds the client plan: personalized before/after sample edits for each prospect, with outreach drafted for approval (nothing sent without the owner's OK).

## 3. "AVE Edit Machine" web page (live demo + lead magnet)
- A creator drops in a clip and watches it run through the AVE pipeline on screen: clip selection, captions, motion, sound, ready to post (same stages as the promo film's dashboard).
- Ends with a CTA to DM "SAMPLE" or book a call; captures the lead.
- Built as a published web page (artifact or deployed site), using the dashboard design language from `film/`.
