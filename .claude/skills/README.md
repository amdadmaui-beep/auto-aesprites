# Video editing skills

Project skills that Claude Code loads automatically in any session on this repo (local or cloud).

- `remotion-*` — Remotion video skills from the official Remotion Claude Code plugin
  (v4.0.528, MIT license, https://github.com/remotion-dev/claude-code-plugin).
  Start with `remotion-best-practices`, which routes to the others.
- `motion-studio-rules` — render contract, look, sound and score-and-fix loop for motion films.

Cloud sessions already have `ffmpeg`/`ffprobe`, Node and Python available for editing.
