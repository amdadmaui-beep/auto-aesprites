The AVE wordmark, as transparent PNGs. Each file is a single-colour mark, so choose the file by its background:
- `ave-wordmark-black.png`: ink `#0e0e0e`, for Paper backgrounds.
- `ave-wordmark-paper.png`: paper `#f3f2ee`, for Ink backgrounds.
- `ave-wordmark-lime.png`: lime `#c8ff2e`, for Ink end cards only.
